# 為何人工智能商品大量經香港出口？——香港作為全球 AI 供應鏈樞紐的深度研究

- 研究日期：2026-11-26
- 整理及核心資料核對日期：2026-11-27
- 用途：研究素材、文章撰寫及簡報製作；非已發表文章
- 語言：繁體中文
- 關鍵詞：香港、人工智能、AI硬件、晶片、半導體、轉口貿易、自由港、大灣區、企業出海、供應鏈金融

## 1. 核心結論

AI商品並非法律上必須經香港出口。香港的優勢是把自由港、航空物流、毗鄰內地製造基地、電子零部件分銷網絡、多幣種結算、貿易融資及國際商業制度結合起來，降低跨境供應鏈整體交易成本。

更重要的是，香港的AI貿易並非單向幫內地企業出海。港大經管學院研究估算，2026年上半年約70%的香港AI相關商品轉口貨值以中國內地為目的地。香港同時服務內地算力需求及海外市場，是雙向樞紐。

香港並非必須自己生產AI晶片，才可分享AI產業增長。真正的長期機會，在於交易、分銷、交付、融資、企業國際營運等高增值功能。

### 2.2 「AI相關商品」是甚麼？

主要是集成電路、處理器、控制器、記憶體、資料處理設備、固態儲存及其他相關電子零部件。GPU、AI伺服器及網絡設備等可作產業用途例子，但統計分類相當廣泛，不等於所有統計商品最終均用於AI。AI軟件及SaaS通常屬服務或其他交易，不應混入實體商品出口統計。

解讀：香港一方面向內地供應鏈輸入海外硬件，另一方面協助內地及其他亞洲製造商接觸國際客戶。不能將所有轉口解釋成中國製成品銷往美國，也不能從彙總數據辨認單一貨物的最終使用者。

## 4. 企業為何選擇香港：七個商業機制

### 4.1 全球供應鏈高度分工

AI硬件涉及晶片設計、晶圓製造、封裝測試、記憶體、材料、設備及系統組裝等跨境環節。例如中國內地、美國及其他地方有設計企業，台灣有晶圓代工，韓國有記憶體，越南及其他東南亞地區有封測與組裝。香港可承擔不同供應商及客戶之間的採購、集貨、存貨和分銷管理，而不是每個生產環節都在香港完成。這是示意分工，不是固定運輸路線。

### 4.2 自由港及單獨關稅區

香港《基本法》第112、114至117條涵蓋外匯自由、自由港、自由貿易、單獨關稅區及產地證制度。一般貨物進出香港不徵關稅，沒有普遍VAT或GST；部分應課稅品及受管制貨品另有規則。

對高價值庫存，企業可在確定最終客戶前使用香港作區域分銷中心，避免提前進入最終進口市場的稅制及減少資金佔用。這不代表目的地關稅或增值稅消失；內地保稅區與其他自由貿易區也能提供部分同類功能。

來源：[基本法第五章](https://www.basiclaw.gov.hk/en/basiclaw/chapter5.html)、[香港海關貨物清關](https://www.customs.gov.hk/en/service-enforcement-information/cargo-clearance/)。

### 4.3 高貨值、低重量與航空物流

晶片等電子零部件往往適合快速航空配送，庫存成本、交貨速度及交付可靠性可能比單位運費更重要。2025年香港機場處理507萬噸貨物，全球貨運量排名第一；相關空運貿易貨值約4.965萬億港元，佔香港對外貿易貨值逾45%。

2026年第三季，空運貨物吞吐量按年增1.0%，空運貿易貨值卻增54.4%。政府指出差距可能反映AI相關電子產品較高的貨值重量比；不能據此直接計算AI貨物的每公斤價格。2026年首三季，航空及陸路合計佔商品貿易貨值約92%。

來源：[機管局空運概況](https://www.hongkongairport.com/en/the-airport/air-cargo/)、[2025年全球貨運機場排名](https://www.hongkongairport.com/en/media-centre/press-release/2026/pr_1859)、[2026年第三季經濟報告，2.16–2.18段](https://www.hkeconomy.gov.hk/en/pdf/er_26q3.pdf)。

### 4.4 背靠深圳、東莞及大灣區製造基地

珠三角提供研發、電子製造、組裝及配套，香港提供國際物流、商務與交付能力。香港國際機場東莞空港中心將部分出口貨物的安檢、打板和收貨移至東莞，再經海路銜接香港機場禁區，亦支援反方向進口。

截至2025/26年度末，已有30家航空公司及144家香港代理商參與，貨運量和貨值的按年增幅均超過90%。永久設施第一期預計2027年全面投入運作；此屬當時預期，不是已竣工的事實。

來源：[香港機管局2025/26年度公布](https://www.hongkongairport.com/en/media-centre/press-release/2026/pr_1875)。

### 4.5 香港處理貨流，也處理資金流

跨境電子貿易可涉及多幣種收付款、信用證、存貨融資、應收帳款融資、外匯對沖、商業信用保險和離岸人民幣結算。高價值庫存往往令營運資金安排特別重要。香港銀行及專業服務體系可提供上述功能，但是否獲得融資、成本多少、能否開戶皆依企業背景及銀行審核，不是註冊香港公司即可自動獲得。

### 4.6 電子分銷產業的網絡效應

香港長期累積了電子零部件買家、分銷商、供應商、物流及品質管理服務商。供應商和客戶的聚集，配合既有信用、倉儲及交付網絡，可降低搜尋成本及提升交付效率。香港貿發局指出，香港貿易結構正向較高技術含量和價值的商品轉移，空運與供應鏈服務的重要性日益突出。

來源：[香港貿發局 Hong Kong's Evolution into a High Value-Added Trade Hub，2026-09-28](https://research.hktdc.com/en/article/MjQzOTM2OTY1MQ)。

### 4.7 國際商事制度、法律及稅務

普通法、商業合同、國際仲裁、會計及跨境服務有助企業設立區域總部及管理交易。合資格法團的兩級制利得稅首200萬港元應評稅利潤為8.25%，超過部分為16.5%。地域來源徵稅並非自動離岸免稅；須根據實際產生利潤的商業活動及所在地判斷，並留意適用的跨境稅務、關聯交易、常設機構及其他規則。

來源：[稅務局兩級制利得稅](https://www.ird.gov.hk/eng/faq/2tr.htm)、[稅務局利潤來源指引DIPN 21](https://www.ird.gov.hk/eng/pdf/dipn21.pdf)。

## 5. 出口管制與原產地：香港不是規避監管的豁免地

- 美國商務部工業與安全局（BIS）確認，2020年12月23日起，香港在美國《出口管理條例》（EAR）下的出口、再出口及境內轉移原則上按中國目的地待遇處理，除非有明文例外。
- 香港本身有戰略物品進出口管制及相關牌照制度；是否適用取決於產品、交易與法律規定。
- 香港自由港地位只說明香港自身的關稅制度，不意味免除目的地關稅、出口管制或其他國家的法律。
- 單純轉運、重包裝或改用香港公司發票，不會自動改變原產地。香港原產地認定涉及實質轉型；進口目的地也有自身規則。
- 雖然BIS指出存在非法轉運風險，但現有總體貿易數據不足以證明香港AI商品增長主要由規避管制造成。
- 個別交易必須核實產品分類、適用管制、最終用途、最終使用者及必要許可；不可將本研究當作交易合規意見。

來源：[BIS香港出口管制](https://www.bis.gov/licensing/country-guidance/hong-kong-export-controls)、[香港工業貿易署進出口管制](https://www.tid.gov.hk/en/our_work/import_export_licensing_control/overview.html)、[香港產地來源證制度](https://www.tid.gov.hk/en/our_work/import_export_licensing_control/factory_registration_certificate_origin/resource_centre/publications/fact_sheet_hk_co.html)。

## 6. 內地企業出海的兩個模式

**模式A：實體貨物經香港。** 工廠、國際供應商 → 香港實體倉儲、分銷及物流 → 目的地客戶。適用於高貨值、快速交付、多目的地分銷、庫存集中等需求。

**模式B：商業交易在香港管理，貨物直接交付。** 香港公司負責真正的海外銷售、合同、採購、融資、結算或財資管理，貨物從生產地直接運往客戶。這是離岸貨物貿易的可能形式，不一定計入香港實體轉口商品統計。

企業不應僅為了形式在港設公司或安排貨物繞道。應比較香港方案與直接出口、內地保稅倉、新加坡等其他方案的實際總成本：物流與清關、庫存資金佔用、交付時間、匯兌和融資、關稅及稅務、法律合規與實際營運人員。

| 企業類型 | 值得評估的香港功能（定性商業判斷） |
| --- | --- |
| 半導體及電子零部件分銷 | 庫存、跨境交付、資金及供應商管理 |
| AI伺服器與數據中心設備 | 國際採購、項目融資、售後 |
| 機械人及智能穿戴 | 品牌、海外銷售、分銷及服務 |
| AI軟件及SaaS | 合同、收款、知識產權及國際營運；不等於商品轉口 |
| 低價代工 | 視乎物流與運營成本，直接出口可能更合適 |

## 7. 香港究竟從龐大貨值中賺了多少？

轉口貨值不等於本地GDP、企業收入或利潤。一批商品假設採購價1億港元，出口價1.05億港元，商品買賣毛利是500萬港元；仍須扣除物流、工資、融資等成本。這是示意算例，不是AI行業實際利潤率。

政府統計處2024年進出口貿易行業調查：

| 指標 | 2024年（億港元） |
| --- | ---: |
| 行業總收益 | 45,233 |
| 盈餘總額 | 4,308 |
| 盈餘佔收益 | 9.5% |
| 行業增加價值 | 4,933 |

來源：[政府統計處2024年行業統計](https://www.censtatd.gov.hk/en./press_release_detail.html?id=6729)。

上述數據屬整個進出口貿易業，不能用9.5%乘2026年AI相關商品出口貨值估算香港AI利潤。尚未取得可準確分拆2026年AI商品轉口業務本地增加價值及淨利潤的資料。

香港可獲得的經濟價值還包括本地物流、專業服務、融資及風險管理、企業管理就業等；不同項目可能重疊，不可簡單相加。

## 8. 未來的三層機會及風險

1. 現有優勢：AI硬件及零部件區域集散、專業倉儲、品質檢測與快速配送。
2. 產業升級：AI企業的國際銷售總部、財資中心、貿易融資、合規及知識產權服務。
3. 長期可能：AI研發、晶片設計、算力服務、科技資本與國際標準協作。

以上是研究推演而非必然預測。主要風險包括國際貿易和科技政策、出口管制、供應鏈遷移、區域物流競爭、AI投資周期、晶片和記憶體價格波動，以及高昂本地成本。貨值增長亦可能受價格因素放大。

香港的歷史角色可概括為製造業出口中心 → 轉口貿易中心 → 金融及專業服務中心 → 科技供應鏈與跨境商業營運樞紐。這些角色可以疊加，而非相互取代；此為分析框架，不是官方分期。

## 9. 可供文章或簡報使用的主線

- 開場：2026年10月香港整體出口按年增65.6%，令人意外的是主要動力來自AI相關電子產品。
- 第一個反差：香港不是大規模晶片製造基地，何以成為AI貿易重要樞紐？
- 第二個反差：港大估算約70%的AI相關轉口商品以內地為目的地，香港也是把全球資源引進內地的窗口。
- 解釋機制：自由港、空運、高貨值重量比、大灣區製造、電子分銷網絡、貿易金融、國際商業制度。
- 澄清誤解：經香港不代表可以避開晶片出口管制，也不自動改變原產地。
- 結尾：香港不一定要成為全球最大的AI生產基地，也可憑藉連接全球供應鏈的能力創造本地價值。
